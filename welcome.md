## Useful shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+P` | Toggle Preview / Raw Markdown |
| `Ctrl+N` | Create a new note |
| `Ctrl+O` | Open a note |
| `Ctrl+Enter` | Toggle the task at the caret |
| `F2` | Rename the active note |
| `Ctrl+Right` | Move to the next open note |
| `Ctrl+Left` | Move to the previous open note |
| `F1` | Show every shortcut |

## Tips

- JotPin autosaves after a short pause; use `Ctrl+S` to save immediately.
- Use **Side**, **Center**, or **Full Screen** to match the way you are working.
- Your open tabs and active note return when JotPin reopens.
- Open **Settings** with `Ctrl+,` to choose your notes folder, Side edge, tab rows, and shortcuts.
- Closing the only tab opens a fresh blank note, so JotPin is always ready.
